## 这是什么

coderoadmap.cn 是一个中文编程学习导航站，解决的是「先学什么、后学什么」。它把学习路径拆成 91 条可执行路线图，每条路线的节点对应一节带讲义的课时，学完能立刻做题验证。覆盖 7 大类：AI 与智能体、编程语言、框架与生态、全栈开发、数据结构与算法、DevOps 与运维、面试准备。

站内内容分两层。**路线图**负责阶段划分与依赖顺序，节点上写明该阶段要掌握的具体要点；**课程**负责逐节讲义，149 门课平均 13 节，每节配自研练习题与即时判分。两者都免费开放，学习进度只存在浏览器本地，不做账号门槛。

其中 143 门课程为站内原创讲义，其余 6 门为公开课程的中文整理，来源与授权在各页面标注。
